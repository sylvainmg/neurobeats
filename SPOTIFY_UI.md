**Référence UI : Spotify Web (actuelle, 2024-2025)**

Structure Spotify à copier :

- Dark mode achromatic : #121212 (cards), #181818, #1f1f1f (surfaces), #000000 (canvas)
- Layout 2-colonnes : sidebar fixe LEFT + main content RIGHT
- Album art-driven (content-first darkness)
- Pill-shaped buttons (border-radius complet, 500px–9999px)
- Circular controls (avatars, play buttons = 50% border-radius)
- Card grid : carrés (album covers) + circulaires (avatars)
- Subtle shadows : rgba(0,0,0,0.5) 0px 8px 24px
- Uppercase button labels + letter-spacing 1.4px–2px

**Adaptation NeuroBeats (BLEU au lieu de vert Spotify) :**

- Primary accent : #0066FF (bleu vif) — remplace #1ed760 (Spotify Green)
- Secondary accent : #00D9FF (cyan) — pour détails, hover
- Canvas/Background : #0F1419 (noir bleuté, pas pur noir)
- Card background : #1A1F2A (très bleu foncé, pas #121212)
- Text : #FFFFFF (blanc comme Spotify)
- Subtle blue tint partout (même atmo que Spotify, mais BLEU)

**Visuels :**

- Sidebar : navigation, playlists (Spotify-style)
- Main area : search, recommendations, now playing
- Player bottom : minimal (Spotify-inspired)
- Album art : protagoniste (même que Spotify)
- One accent color (#0066FF bleu) → jamais décoratif, toujours fonctionnel

Reste fidèle à la structure Spotify, change juste le vert en bleu.
